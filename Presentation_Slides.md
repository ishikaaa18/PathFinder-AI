**1. AI Resume Analyzer**

- One click generates a full, professional cover letter.

## Slide 7: SWOT Analysis

**Strengths:**
*   End-to-end career platform — no competitor offers all features in one place.
*   Zero ML training cost — Gemini API provides world-class AI instantly.
*   Personalized output — every recommendation, roadmap, and letter is unique to the user.
*   Document generation — resume + cover letter in one session.

**Weaknesses:**
*   Dependent on external AI API (Gemini) uptime and rate limits.
*   Skill Matrix uses estimated scores, not verified/tested scores.

**Opportunities:**
*   University/college partnerships for placement preparation.
*   Affiliate model with Coursera, edX, Udemy for recommended courses.
*   Expansion into Interview Prep and Job Description Matching.

**Threats:**
*   LinkedIn or Google building a similar integrated product.
*   AI hallucination risk in generated career/course data.
