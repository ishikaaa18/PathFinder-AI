1. What is PathFinder AI?

PathFinder AI is a fully functional, AI-powered career guidance web application built to assist students and job seekers in identifying the most suitable career path based on their individual skills, academic background, and interests. The platform integrates Google's Gemini AI (a large language model) to function as a 24/7 personal career coach — generating tailored career recommendations, personalized learning roadmaps, resume gap analysis reports, professional cover letters, skill assessments, and career goal tracking — all delivered through a single, cohesive web interface. The system eliminates the need for expensive career counselling by providing instant, data-driven guidance accessible to anyone with an internet connection.

5. User Journey
  1. Sign Up & Build Profile
    User registers and enters their skills, interests, and academic qualifications.
  2. Receive AI Career Recommendations
    Gemini AI suggests best-fit careers complete with percentage match scores and justification.
  3. View Personalized Learning Roadmap
    A week-by-week study plan is generated with curated course links from Coursera, edX, and Udemy.
  4. Upload Resume for AI Analysis
    AI reads the uploaded PDF resume and compares it against the target career to reveal skill gaps.
  5. Generate a Cover Letter
    One click generates a tailored, professional cover letter using the resume analysis data.
  6. Set Goals & Take Skill Quiz
    User sets career goals on a Kanban board and takes MCQ quizzes to verify skill progress.
