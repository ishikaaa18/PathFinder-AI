ABSTRACT

PathFinder AI is a comprehensive AI-driven career guidance platform designed to bridge the gap between education and employment. Leveraging the MERN (MongoDB, Express, React, Node) stack and Google's Gemini large language model, the platform provides a personalized "Input-to-Insight-to-Action" journey for students and job seekers. The system analyzes user profiles including skills, interests, and qualifications to generate tailored career recommendations with high confidence scores. It further provides personalized learning roadmaps with verified course links, an AI-powered resume analyzer that identifies skill gaps against target roles, and an automated cover letter generator. Additional modules include a Kanban-style goal tracker, a categorized skill assessment quiz, and a market insights dashboard. The project demonstrates the potential of LLMs in creating zero-training-cost AI interventions for career coaching, offering a scalable and accessible alternative to manual counseling. The architecture ensures secure, authenticated access and a premium responsive user experience across both dark and light modes.

Keywords: AI Career Coach, Google Gemini, MERN Stack, Career Recommendation Engine, Resume Analysis, Learning Roadmaps, Skill Gap Visualization, Cyber Security Careers, Career Development, NLP in Career Guidance.

1. INTRODUCTION

1.1 Purpose

PathFinder AI is a comprehensive, AI-driven career guidance platform. Its purpose is to help students and job seekers identify optimal career paths by analyzing their skills, interests, and qualifications — and then providing a full ecosystem of tools to bridge the gap between their current state and their career goal. The platform leverages Google's Gemini large language model (LLM) for all AI-generated content, from career suggestions to personalized learning roadmaps, resume feedback, and professional cover letters.

1.2 Aim

The aim of the project is to build a fully functional, production-ready web application that acts as a personal career coach. The system provides a streamlined "Input-to-Insight-to-Action" journey: users enter their profile, receive AI-generated career recommendations, can check their resume against their target role, track their learning goals, assess their skills, and generate application documents — all within a single platform.

1.3 Objectives

  • Core Recommendation Engine: Develop backend logic that returns tailored career recommendations with confidence scores.
  • Resume Analysis: Implement an AI-powered resume checker that compares a user's PDF resume against a target career.
  • Skill Visualization: Represent the gap between current skills and ideal profiles using interactive radar charts.
  • Goal Tracking: Allow users to manage career-related goals on a Kanban board.

2. SYSTEM ARCHITECTURE

2.1 User Interfaces

The platform features a modern, responsive user interface built with React.js and TailwindCSS. Key interfaces include the dynamic Hero carousel on the landing page, a compact data-rich Dashboard, a timeline view for Career Paths, and interactive charts for Skill Visualization. The design supports both dark and light modes with persistent user preferences.

2.2 Software Interfaces

  • MERN Stack: MongoDB, Express.js, React.js (Vite), Node.js.
  • AI Interface: Google Gemini (gemini-flash-latest) API.
  • Data Visualization: Recharts for radar and progress charts.
  • Authentication: JWT-based secure session management.
